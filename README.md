# 双星余烬 · Embers of the Twin Stars

《双星余烬》是一款面向电脑端的日式幻想回合制战棋游戏。蚀月降临，北境诸国的烽火相继熄灭，唯有古老神殿坠落的双星仍在黑暗中燃烧。玩家将跟随凯尔与莱拉的旅程，集结同伴、穿越险境，寻找让群星重燃的希望。 游戏将精细绘制的幻想世界地图、3D 战场与像素角色融合，搭配透明手绘半身立绘和羊皮纸书册界面，营造翻阅远征纪事般的冒险体验。玩家沿道路探索城镇与神殿，在战斗中利用地形、移动范围、兵种与装备制定策略，通过招募、成长和转职打造自己的队伍。 项目采用 TypeScript、Phaser 与 Three.js 开发，支持鼠标与键盘操作。当前已实现星落桥、月影峡道两处主线战场，以及世界地图探索、可重复支线讨伐、队伍编成、装备交换、魔法与自动存档等核心系统，并持续完善剧情、关卡和交互体验。

一款受早期日式战棋启发的原创浏览器游戏，现有星落桥、月影峡道两场战役。两关战场统一使用 Three.js 真实 3D 地形、受光像素角色与地图内战斗演出；世界地图、村庄、整备和战斗规则继续保留。

## 平台

仅支持电脑端（鼠标、键盘），不再适配或验收手机、触屏与手机竖屏布局。战场 HUD 以统一桌面画板随窗口缩放，建议 1280×720 及以上。此约定优先于历史文档中的手机适配记录。

## 游玩

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4174 --strictPort
```

打开 `http://127.0.0.1:4174/`，保持终端运行。也可使用 `npm run dev`，打开终端显示的地址（默认端口 5173）。端口被占用时，先检查是不是已有游戏服务，不必重复启动。

存档保存在浏览器本地。同一浏览器中请一直使用相同的地址：`localhost`、`127.0.0.1` 和不同端口的存档互不共享。已有进度请选择“继续远征”；开启新篇章会先要求确认覆盖。

两关进入战场后自动加载 3D 场景。月影峡道接入新版 Blender/Godot 同源模型，包含悬崖、远山山林、桥梁、祭坛、瀑布和流动云层，可直接按战棋玩法操作，目前仍可从世界地图直接进入。拖动平移、滚轮缩放，“全图”复位，“聚焦单位”定位角色；月影峡道限制远景方向的旋转和全景平移，放大后可扩大平移范围。画质和动态效果设置不写入战役存档。

两关不再提供经典 2D 战场或旧战斗舞台，旧 `?renderer=classic` 参数和关闭地图演出的偏好均不生效。3D 加载失败会显示重试按钮并保留战斗进度。月影峡道源模型更新后运行 `npm run sync:moonlit`，再运行 `npm test` 和 `npm run build`。当前接入与验收见 [月影峡道与 3D 模式说明](docs/MOONLIT-PLAYABLE.md)；历史迁移文档中的 2D 切换说明已失效。

## 已实现

- 历史版本的主菜单、编队与战场 HUD 曾完成桌面和手机尺寸模拟验收（目前仅维护桌面端）；修复场景退场后的 Esc 捕获及手机背景叠字，并继续调整星落桥植被、石材和光照。见 [本轮验收与场景对照](docs/REPLICA-ACCEPTANCE.md)。
- 标题、对话、战前整备、人物档案、行动菜单、战斗预测、成长和结算界面采用羊皮纸、森林墨色与旧金边饰；大面板有卷轴展开效果，支持减少动态效果。八张新半身像统一为绘制风格。见 [本轮美术更新](docs/CHRONICLE-UI.md)。
- 世界地图：方向键 / WASD 或点击地图操纵小人；抵达节点后，点击确认或按 Enter / 空格才进入。底部目的地按钮负责导航，不自动触发事件。
- 晨雾村：独立可行走场景，拜访补给屋、礼拜堂及村口；补给沿用首次拜访奖励，礼拜堂对话不增加额外治疗规则。
- 星落桥 10×8、月影峡道 12×12 棋盘：带地形成本的寻路，独立树木、植物、建筑、河流、桥梁、祭坛，以及水面微光和环境粒子。
- 两关采用六姿态像素角色，包含交替步行、蓄力、出手与收势；诺克斯、艾琳与祭坛术士使用专属素材。进阶职业数值与转职规则不变。
- 地图逐格步行、面向切换与施法姿态；战斗镜头在 3D 地图内拉近，显示 HP、命中率、伤害，演出蓄力、出手、收势、受击、闪避、反击及追击。
- 独立战斗解析器产生真实命中与伤害时间线，动画不生成或改变结果；完整 / 简略演出、二倍速、跳过及判定记录保留。
- 莱拉仍为星祈骑兵；已习得回复魔法且符合职业条件的角色可施放，当前回复魔法消耗 1 HP，具体射程与效果仍由原数据决定。
- 装备、交换、物品、敌方 AI、威胁范围、经验、成长、招募、神殿转职、胜负条件、章节解锁和本地存档保留。
- 八张手绘肖像覆盖主要人物与敌方形象；诺克斯为独立女性肖像，艾琳与赛勒涅也有独立头像。
- 战场 HUD 按新版设计稿替换为角色选中、战场总览和双页书菜单；支持桌面窗口缩放与减少动态效果设置，不提供手机布局。

## 构建

```bash
npm test
npm run build
```

生产文件输出到 `dist/`。

自动测试覆盖战斗解析、命中 / 未命中、追击、时间线 HP、回复条件、加权移动、两章恢复、补给去重、地图位置存档、招募、转职和精灵资源完整性；新增渲染边界、地形接缝、相机竖屏、逐事件跳过与取消、规则结果一致性和 v1/v2 存档往返检查。此前 2D 版本的验收范围见 [HD-2D 重制说明](docs/HD2D-REMAKE.md)。

素材保存在 `public/assets/hd2d/`，世界地图为 `public/assets/world-map/northern-realms.png`。生成方式、角色约束与最终提示词规格见 [美术清单](docs/HD2D-ART.md)。
