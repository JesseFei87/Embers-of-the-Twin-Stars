# Embers-of-the-Twin-Stars
《双星余烬》是一款面向电脑端的日式幻想回合制战棋游戏。蚀月降临，北境诸国的烽火相继熄灭，唯有古老神殿坠落的双星仍在黑暗中燃烧。玩家将跟随凯尔与莱拉的旅程，集结同伴、穿越险境，寻找让群星重燃的希望。 游戏将精细绘制的幻想世界地图、3D 战场与像素角色融合，搭配透明手绘半身立绘和羊皮纸书册界面，营造翻阅远征纪事般的冒险体验。玩家沿道路探索城镇与神殿，在战斗中利用地形、移动范围、兵种与装备制定策略，通过招募、成长和转职打造自己的队伍。 项目采用 TypeScript、Phaser 与 Three.js 开发，支持鼠标与键盘操作。当前已实现星落桥、月影峡道两处主线战场，以及世界地图探索、可重复支线讨伐、队伍编成、装备交换、魔法与自动存档等核心系统，并持续完善剧情、关卡和交互体验。
