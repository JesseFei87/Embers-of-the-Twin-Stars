# 星落桥背景音乐 v3：同一片星光之下 · 钢琴战记

当前版本按用户反馈将主旋律、和弦、分解伴奏、低音和断奏全部改为钢琴。原簧片主奏和弦乐合成音色均已移除，打击乐较 v2 减半，保留 96 秒段落结构。

`scripts/render-piano.swift` 使用 macOS 自带 General MIDI Acoustic Grand Piano（program 0）离线演奏 816 个 MIDI 音符；不复制或发布系统音库。Python 完成混音，游戏加载版本为 `?v=3`。重新生成需要 macOS、Swift、NumPy，以及可访问 Core Audio 组件的宿主环境。

v3：峰值 −1.72 dBFS，RMS −21.59 dBFS，180Hz 以下占比 2.54%，循环接缝差值 0.0000922。使用钢琴击键与自然衰减，移除持续等响的簧片波形。

## 编曲

原创合成器乐，40 小节，100 BPM，4/4 拍，96 秒完整循环。D 小调，穿插明亮大和弦，使用属和弦制造紧张和回归感。主旋律以四小节主题反复、回答和扩展，高潮提高音区并加入少量低八度呼应。

| 时间 | 段落 | 编排 |
| --- | --- | --- |
| 0–9.6 秒 | 克制开场 | 旋律片段、稀疏拨弦、较高音区的轻弦乐 |
| 9.6–28.8 秒 | 暗流推进 | 主题出现，短音低音和打击节奏加入 |
| 28.8–48 秒 | 逐步蓄势 | 弦乐断奏持续推进，打击乐密度提高 |
| 48–76.8 秒 | 战斗高潮 | 上行旋律、明亮和声、更完整的节奏与段落尾部鼓花 |
| 76.8–96 秒 | 回落与希望 | 逐步减去鼓点和伴奏，留下主题回应，接回开场 |

不是将旧版整体调大音量：删除低八度持续铺底，低音改为短音、居中、无混响；弦乐和拨弦提升音区；仅旋律使用短反射；52Hz 以下滚降，270Hz 附近适量衰减，为主旋律腾出空间。

## 素材与接入

- 素材：`public/assets/audio/starfall-under-the-same-stars.wav`，24 kHz、16-bit、双声道 PCM。
- 作曲与合成脚本：`scripts/compose-starfall-music.py`，依赖 Python + NumPy。全部为原创音符和数学音色，无第三方录音/采样。
- 元数据：`public/assets/audio/starfall-music.json`，version=2。
- 保留星落桥专用播放、原生循环、进入淡入、离开淡出、隐藏标签暂停和音量记忆。默认 55%，设置可调至 0 静音。
- 音符和短反射尾音循环混入开头，避免循环边界被截断。未改变战斗规则或存档。

## 验收

`npm test` 覆盖 v2 标识、96 秒完整小节、无削波、循环接缝、低频占比限制、中频存在感、高潮相对开场/回落的动态差，以及既有音频生命周期回归。

`npm run build` 通过；仅保留既有大包体积提示。

`check.html` 为独立验收与试听页面，直接使用生产音频模块，通过 Web Audio Analyser 读取实际输出；不加入游戏流程。

浏览器实测：实际解码 duration=96、loop=true；播放时钟到 99 秒（超过一整轮）仍有连续音频输出，RMS=0.03157；在高潮段约 60 秒、70% 音量时 RMS=0.11301。浏览器 warn/error 为空。立体声合为单声道后 RMS=0.1115，未出现明显相位抵消。
