## 美术方向

采用八方旅人式 HD-2D 表现：有真实厚度、遮挡和阴影的立体地形，像素纹理与像素角色相结合。冷蓝月光作为主要照明，暖色火盆标示桥头与路径，少量紫色强调女巫祭坛。景深只作用于最远背景和最前景，不能模糊可操作的地面。

重绘沿用南侧出发、中央渡河、北岸守关、东北祭坛的空间关系。图中远景拱形遗迹是装饰背景，不增加新的可通行桥梁。生成图用于视觉定调，精确格位与角色位置以布局图和现有关卡数据为准。

## Blender 搭建建议

以下尺寸为下一阶段白盒建议，不是已修改的关卡参数：

- 采用米制，建议每格 2 m；有效棋盘约 20×16 m，外围峭壁和远景超出棋盘边界，避免悬浮方形底板感。
- 主通道、两岸与桥面先统一在 0 m。河面约 −3 m；祭坛约 +0.6 m；可攀山地约 +0.6–1.2 m，使用可走斜坡衔接；外围峭壁约 4–10 m。
- 桥梁模块按三个并排通行格构造，南北跨河。桥板、桥墩、栏杆、桥头台分别建模。栏杆不能遮挡角色或占用路径。
- 建议模块：直线 / 转角 / 顶面 / 坡道岩壁，草地地面，石路与边缘，木桥构件，月纹平台、祭坛圆台、断裂门拱，完整 / 破损石柱，松树、灌木、草花，火盆。
- 地形模块原点放在底部或网格角，统一比例并应用变换。先做通行面与高差白盒，再加岩层、根系、碎石等细节。
- 像素风来自纹理块面、轮廓与材质，不要把所有几何体做成规则小方块。石壁需要大中小层次，避免密集等尺寸碎块造成噪声。
- 以 glTF/GLB 输出模块，保留有意义的节点与材质名。角色、装饰、碰撞和通行面分别组织，便于在 Godot 中调整。

## Godot 场景建议

- 使用 Y 轴向上的场景；格心 X = `(列 − 4.5) × 2`，Z = `(行 − 3.5) × 2`，北方为 −Z。Blender 导出器负责轴向转换，不再手动重复旋转。
- 固定正交相机，从南向北观察，俯角先试 50–55°，画幅以桌面 16:9 为主；让南侧平台与东北祭坛同时处于可读范围。
- 地形用 3D 网格；人物用朝相机的像素精灵，脚底锚点固定。地面接触阴影与高度一致，避免角色悬浮。
- 像素贴图使用最近邻过滤作为起点，纹理密度保持一致。先保证运动时不闪烁，再调整分辨率、抗锯齿和景深。
- 使用冷色方向光塑造岩壁层次，桥头火盆使用有限范围暖色局部光。暗部保留填充光，雾主要聚集于河床和峡谷远景，不覆盖主路。
- 水面、瀑布泡沫、低雾和火焰独立设置；先验证通行和相机可读性，再增加动画。
- 保留原地图地形语义：森林、山地、河流的移动规则不由装饰网格决定。尤其不可因图中岩壁较高就把原有山地格改成完全不可通行。
