# HD-2D 风格重制验收记录

本轮仅改变表现与导航层，不重新平衡角色、武器、魔法、地形、成长或章节任务。继续使用原独立规则模块和战斗结果时间线。

## 场景与表现

- 世界地图：手绘山河，凯尔小人四向导航、点击行走、抵达确认、位置保存。
- 村庄：独立可行走广场，屋舍、灯光、植被；补给和出村必须到达后确认。
- 棋盘：地面、竖直景物、单位、环境光分层。棋盘外建筑只作装饰，不制造新可通行地形。两张地图的数据和尺寸未变。
- 战斗：六套像素精灵、六姿态共享底部锚点；位移和姿态分开控制，命中时推进原解析器给出的 HP 事件。跳过时应用同一时间线最终 HP。
- 人物：八格现代手绘肖像，人物档案加入性格简介，旧存档头像编号通过表现层映射保留。
- UI：统一深色金边面板、柔和纸色文字、可见焦点、手机操作栏；头像保持正方形，避免卡片变高时拉伸。

## 已执行的自动验证

`npm test`、`npm run build` 均通过。构建仍有 Phaser 单包大于 500 kB 的体积提示，不是错误。

测试执行真实项目规则，使用内存 localStorage，不操作玩家存档。覆盖命中 / 未命中、追击、解析器不修改输入、事件与最终 HP 一致、回复魔法、加权移动、两章状态恢复、地图位置持久化、村庄补给只发一次、招募角色与回合限制、转职保留魔法、全部职业对应的六帧资源。

## 浏览器实测

使用独立测试域名 `hd2d-qa.localhost:4174`，没有清除或修改原玩家地址的存档。

- 新篇章 → 三段对话 → 世界地图 → 村庄 → 步行至补给屋 → 确认领取 → 步行出村 → 返回地图。
- 世界地图 → 星落桥 → 确认 → 剧情 → 整备 → 首章开战。

- 莱拉相邻回复：凯尔从 20/24 回到 24/24，莱拉从 22/22 降到 21/22。
- 米菈攻击、舞台二倍速、跳过、敌方行动、恢复我方第二回合。
- 390×844 窗口：没有横向溢出，棋盘首尾行均可见，缩放后的点击可正确选中凯尔。
- 第二章使用专用测试存档检查开战、赛勒涅详情和独立 p7 头像；另用接敌位置测试骑兵与女巫施法，全部十二张舞台姿态图片加载成功，并返回我方阶段。

边界：没有将本轮验收等同于两章所有路线完整通关；招募与转职在本轮主要通过规则回归测试。第三章仍为原来的后续预告。

## 当前实现边界

这是 Phaser 2D 上的 HD-2D 风格表现，不包含真实 3D 场景、实时景深或物理光照。当前为六套基础兵种视觉，进阶职业共享对应精灵；不是每个进阶职业都新增一套服装。动作是六个关键姿态配合平滑位移、缓动与特效，不是骨骼动画。
