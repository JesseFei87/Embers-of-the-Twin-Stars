# 羊皮纸界面正式接入 · 2026-09-23

## 实现范围

按已审核原型接入村庄、剧情/招募、神殿与晋升、角色详情/魔法书、战斗预测、装备交换、系统设置、记录弹窗、胜负结算、经验反馈、加载/3D 重试、新游戏覆盖确认。

- 复用正式游戏的书册、卷页、按钮与透明立绘素材，真实数据和操作接入现有逻辑。
- 对话立绘改为 330×430，卷页宽 790、最小高 235（1440×810 基准），按桌面窗口统一缩放。
- 鼠标悬停、点击、选中通过底色/文字变化表达，不追加 CSS 边框、轮廓线或内阴影。素材原有金属装饰保留。键盘 Tab 保留可见焦点。
- 世界地图原图、道路移动、3D 战场、战斗规则与存档格式保持原实现。
- 浏览器内设计审核标注未改写，未将对话改稿擅自标为通过。

## 验证证据

`npm run build` 通过；Vite 仍提示已有的大体积 JS chunk。

`npm test` 七组脚本全部通过：战斗/命中/回复/成长与存档、渲染适配与棋格、星落桥、角色动作身份、音乐、月影峡道、世界地图道路及重复讨伐。

实机浏览器使用独立页和内存 localStorage，未读写用户实际存档。部分状态通过开发场景入口设置 fixture，再执行真实按钮与存档流程，非整章从头游玩的证明。

| 操作 | 实测结果 |
| --- | --- |
| 设置画面/声音/辅助切页，静音、减少动态、画质、天气 | 切页正确；静音显示与 renderer 天气状态同步 |
| 鼠标点击设置页签、悬停战场菜单 | border-width 0px、outline none、box-shadow none |
| Tab / Esc | 键盘焦点可见；弹窗/书册返回原场景 |
| 角色能力、空魔法书、莱拉回复魔法装备 | 显示真实数据；装备后仍停在魔法页 |
| 相邻敌人战斗预测、详细预测、取消 | 数值来自规则；详细内容展开；取消返回操作 |
| 凯尔和米菈交换装备 | 双方物品实际互换；凯尔行动结束 |
| 神殿等级不足、可晋升、确认晋升 | 不足时禁用；晋升后勇者 Lv.1 写入隔离存档 |

| 升级反馈、战场剧情 Enter 继续 | 显示真实成长；对话正常继续 |
| 胜利、失败返回整备 | 战果写入；失败按钮进入 preparation 场景 |
| 模拟 3D 资源失败、点击重试 | 重试恢复 enabled；状态卷页移除，无 2D 回退 |
