# 月影峡道接入与两关 3D 模式

2026-09-19。星落桥、月影峡道战场均自动加载 Three.js；世界地图、整备、村庄保留原有界面。

## 场景来源

`npm run sync:moonlit` 将 Godot 使用的 `godot-starfall/assets/models/moonlit_environment.glb` 和 `moonlit-layout.json` 复制到 `public/assets/moonlit/`，同时记录 SHA-256。浏览器直接使用同一模型，比例为原生坐标的 1/2，未修改原生模型。

`MoonlitEnvironment.ts` 接入峡壁、桥、祭坛、植被和远山，并移植流水、瀑布、火焰、星空、月牙、移动云层与雾。远山下缘透明渐隐，树冠按局部区域淡出。浏览器光照/后处理由 Three.js 实现，不是嵌入 Godot 可执行程序。

`moonlitHeight` 对齐原生地面、桥面、南端平台及祭坛阶梯；全部 144 格中心高度与原生布局逐格核对。地图仍为 12×12、7 名敌人，艾琳和祭坛术士继续使用专属形象。寻路、出生点、职业、招募条件及战役存档规则未修改。月影峡道仍保持预览开放。

## 3D 唯一入口

- 移除战场 2D 切换按钮和旧舞台演出设置。
- `?renderer=classic` 不再生效；旧 `mapCombat:false` 偏好读入时迁移为开启地图演出。
- Phaser 仍承载战斗状态和内部时间线，但战场相机始终隐藏，所有可见战场和战斗演出走 3D。
- 加载失败或 WebGL 上下文丢失后显示 3D 重试面板，不自动回退；敌方阶段读档等待 3D 就绪后启动一次。
- 月影峡道全景缩放上限为完整布景范围；全景平移限制 ±0.5，放大后逐步扩大至 ±2。水平旋转扩大至左右各约 26°，俯视角约 30°–57°，默认约 37°；全图复位同时重置朝向。人物贴片随相机俯仰和水平朝向，地面环与脚底锚点保持不动，避免俯视压扁人物。

## 验证

`npm test` 六组验证通过，包含模型一致性、144 格高度、四种桌面尺寸、镜头边界、旧偏好、战斗/AI/存档兼容。`npm run build` 通过；保留 Vite 对现有大包的提示。

真实浏览器验证：

- 1440×810：月影峡道选择凯尔、从 (4,11) 移动至 (4,9)、待机成功。
- 两关分别通过“战斗 → 选敌 → 开始战斗”执行地图内演出；攻击、反击、HP 与行动状态正常。
- 月影峡道战斗后重新加载保留凯尔的位置、20 HP 与已行动状态。
- 中断月影峡道 GLB 请求后显示重试，2D 相机仍隐藏；解除中断后恢复同一战斗。
- 第 1 回合敌方阶段中断加载时不推进；重试后只推进一次，进入第 2 回合我方阶段，仅有一个 3D 渲染宿主。
- 检查 1280×720、1440×810、1920×1080 和 1074×909 桌面画面，以及战斗近景、全景平移/旋转边界。发现全景右下外缘后收紧镜头并复查。
- 最终两关实战与重试运行未报告浏览器错误。

验收素材见 `moonlit-integration-evidence/`。本次在当前桌面浏览器验证；不把当前机器结果等同于所有显卡的性能保证。
