## 修改

- 修正 Three.js 战场将诺克斯 `e2` 强制映射为 mage 的原因。职业数据本身仍是 raider（斥候），没有修改属性、规则、AI 或存档格式。
- 新增红发、轻甲、暗红围巾、短刃的专属六动作：待机、两帧奔跑、蓄势、突刺、受击。战场、经典渲染、战斗演出、编队预览均使用同一图集。
- 原始生成图集保持不变。纹理上传时按 manifest 的边界和脚底位置裁取；所有动作保持同一像素缩放比例，落脚点固定在 128×128 画布底部中心。地图站立高度 52px，经典演出站立高度 92px，避免蓄势披风被裁掉。
- 诺克斯、黑铠兵、蚀月骑士、暮鸦分别使用独立透明半身立绘。黑铠兵为普通封闭头盔；骑士为红缨、红目和更华丽的重甲；暮鸦保留红色兜帽与面罩；诺克斯露出红发。
- 共享立绘映射按角色 ID 接入，诺克斯招募后在编队和战场均保留专属外观。第二章同类敌人的立绘也接入。
