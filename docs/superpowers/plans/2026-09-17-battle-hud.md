# 战前与战斗 HUD 实施计划

Goal: 按已确认交互图接入战前整备、出征、角落 HUD 和临时菜单。
Architecture: PixelBattleScene 保持玩法控制；PreparationScene 将新关卡标记为战前。独立 UI 存储保存战前指纹，不更改战役存档 schema；旧档默认进入战斗。

- [x] 浏览器失败用例：新关卡显示出征，战前不可移动，编队可调整，点击出征隐藏工具栏。
- [x] 接入状态与菜单；临时菜单阻止地图输入；设置、编队返回不重置状态。
- [x] 桌面/手机角落 HUD；选中单位才显示资料与行动；地图演出收起大面板。
- [x] 验证战前/战斗刷新恢复、菜单往返、真实移动战斗、两章/经典画面，执行 npm test 与 build，保存截图。
